## Problem

Train an MLP (PyTorch) to estimate P(home win), P(draw), and
P(away win) in international national team matches, using a softmax output
and cross-entropy as the loss function.

The validation approach: the model is trained only on data prior to the 2026 FIFA World Cup and tested directly against the 104 actual matches from that tournament, evaluating probability calibration, not just accuracy.

A linear baseline (logistic regression) is also trained on the same features, to empirically test whether the MLP's non-linearity is actually warranted for this problem, rather than assuming it.

## Data

Public Kaggle dataset "International football results from 1872 to 2026"
(includes a community extension covering the 2026 World Cup). Download `results.csv`
and place it in `data/raw/results.csv` (not versioned in this repository).

- **Training:** matches from 2000-01-01 until the day before the 2026 FIFA World Cup (2026-06-10).
- **Test:** the 104 matches of the FIFA World Cup 2026 (06/11 to 07/19/2026).

Features (calculated from the history available up to the date of each match):

- `elo_diff`: difference in Elo rating between the home and away teams (Elo calculated sequentially over the entire history since 1872, so it does not start "reset" in 2000)
- `home_flag`: home advantage indicator (0 if the match is played at a neutral venue)
- `elo_home_interaction`: `elo_diff × home_flag` — tests whether home advantage depends on the strength gap between the two teams
- `form_diff`: difference in points earned over the last 10 matches of each national team

## How to Run

```bash
pip install -r requirements.txt

python src/build_dataset.py     # generates data/processed/{train,test,team_state}.csv
python src/train.py             # trains the MLP
python src/evaluate.py          # cross-entropy, accuracy, calibration/confusion/ROC plots
python src/train_linear.py      # trains the linear baseline
python src/compare_models.py    # compares MLP vs. linear baseline on the test set
```

The full pipeline (with explanations and discussion of results) is also available as a runnable report in `notebooks/trabalho_final.ipynb`.

## Predicting a hypothetical match

Once the model is trained (`python src/train.py` has been run at least once), you can get outcome probabilities for any matchup between two teams present in the dataset:

```bash
python src/predict.py "Brazil" "Spain"              # Brazil as home team
python src/predict.py "Brazil" "Spain" --neutral    # neutral venue, no home advantage
```

This uses each team's most recent Elo rating and recent-form points (from `data/processed/team_state.csv`, generated by `build_dataset.py`) to build the same feature vector used during training, and prints the predicted probability of each outcome.

## Results

Generated in `outputs/figures/` after running `evaluate.py`:

- `learning_curve.png` — training/validation cross-entropy per epoch
- `calibration_curve.png` — predicted probability vs. observed frequency on the 2026 World Cup (the project's primary evaluation metric)
- `confusion_matrix.png` — 3×3 confusion matrix on the 104 World Cup matches
- `roc_curves.png` — one-vs-rest ROC curve and AUC per class

The trained model weights are saved to `outputs/trained_model.pt` (MLP) and `outputs/trained_model_linear.pt` (linear baseline).
